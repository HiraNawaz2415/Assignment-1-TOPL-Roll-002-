Assignment:Mobile Sensor Data Parsing, CSV Generation, and Analysis
1. Problem Understanding:
-------------------------
The task is to read a sensor log file generated by the 'GetSensorData' Android app. 
The file contains data from multiple sensors (ACCE, GYRO, MAGN, AHRS, LIGH, SOUN, WIFI, etc.) 
with each line representing a sensor reading. The data fields are separated by semicolons (;). 
Some lines contain comments starting with '%' and should be ignored. 

Each sensor type has its own data structure and number of fields. For example:
- ACCE: AppTimestamp, SensorTimestamp, Acc_X, Acc_Y, Acc_Z, Accuracy
- GYRO: AppTimestamp, SensorTimestamp, Gyr_X, Gyr_Y, Gyr_Z, Accuracy
- MAGN: AppTimestamp, SensorTimestamp, Mag_X, Mag_Y, Mag_Z, Accuracy
- AHRS: AppTimestamp, SensorTimestamp, PitchX, RollY, YawZ, RotVecX, RotVecY, RotVecZ, Accuracy
- LIGH: AppTimestamp, SensorTimestamp, Light, Accuracy
- SOUN: AppTimestamp, RMS, Pressure, SPL
- WIFI: AppTimestamp, SensorTimestamp, SSID, MAC, RSS

Goal:
1. Convert the sensor log file into a **CSV file** containing all sensors combined.
2. Generate **separate CSV files** for each sensor type with proper headers.

Challenges:
- Different sensors have different numbers of fields.
- Some lines may have missing fields.
- Comments and empty lines must be ignored.
- Ensure the CSV files have human-readable headers.
